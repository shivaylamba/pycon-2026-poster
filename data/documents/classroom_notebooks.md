# Classroom Notebook Guidance

For students and educators, the best LLM benchmark is one that can be run in a
notebook without special infrastructure. A mock provider is useful for teaching
the measurement pipeline, while a local provider such as Docker Model Runner is useful for
comparing CPU and GPU behavior on a real machine.

Every figure should label whether energy is directly measured or estimated.
That keeps the notebook honest and helps attendees adapt it to their own
hardware.
